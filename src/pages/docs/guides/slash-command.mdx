## Adding a New Command

<Callout title="Consumers should use extraFeatures">
  To add a command together with its node and plugin without editing
  internals, contribute one `extraFeatures` descriptor and list the command id
  in its `slashCommandIds`. Editing the three slash-command files below is
  only for contributing a *built-in* command shipped in the default registry.
</Callout>

The flow is still the same: extend the ID union, add a command entry, and
register the executor. The source blocks above are the canonical reference
for the exact shapes currently in use.

### 1. Extend the type union

```ts
// types.ts -- add your id to SlashCommandId
export type SlashCommandId =
  | "paragraph"
  | "h1"
  | /* ... */
  | "my-command";
```

### 2. Add the menu entry

```ts
// commands.ts
import { MyIcon } from "lucide-react";

export const SLASH_COMMANDS: SlashCommand[] = [
  // ...existing entries...
  {
    description: "My custom block",
    icon: MyIcon,
    id: "my-command",
    keywords: ["custom", "my"],
    label: "My Block",
  },
];
```

### 3. Add the executor

```ts
// executors.ts
export const SLASH_COMMAND_EXECUTORS: Record<SlashCommandId, ...> = {
  // ...existing entries...
  "my-command": (element) => {
    const myNode = $createMyNode();
    element.replace(myNode);
    myNode.selectEnd();
  },
};
```

<Callout title="image and youtube are stubs">
  Both `image` and `youtube` map to `applyParagraphCommand` in the executors.
  The actual insertion is handled by a prompt dialog in the plugin's
  `handleExecute` function. The executor just normalizes the cursor position
  before the dialog opens.
</Callout>
