## Adding a New Command

<Callout title="Use extraFeatures for feature and consumer commands">
  To add a command together with its node, plugin, and markdown transformers
  without editing slash-command internals, pass an `ExtraEditorFeature`
  descriptor via `extraFeatures` and define `slashCommands: [{ command, run }]`.
</Callout>

```tsx
import { SparklesIcon } from "lucide-react";

const myFeature: ExtraEditorFeature = {
  id: "my-block",
  nodes: [MyBlockNode],
  plugin: MyBlockPlugin,
  slashCommands: [
    {
      command: {
        description: "Insert my custom block",
        icon: SparklesIcon,
        id: "my-block",
        keywords: ["custom", "my"],
        label: "My Block",
      },
      run: (editor, targetNodeKey) => {
        editor.dispatchCommand(INSERT_MY_BLOCK_COMMAND, { targetNodeKey });
      },
    },
  ],
};
```

<Callout title="Dialog-backed insertion flows" variant="info">
  Commands that need user input (such as `image`, `youtube`, and `columns`)
  dispatch an open-dialog command from their `run` callback with the optional
  `targetNodeKey`. The feature plugin owns its own dialog state and only mutates
  the document once the user confirms — cancelling leaves the document
  untouched.
</Callout>
