## container-node.ts

Renders as a `<div>` with `data-lexical-layout-container` and
`style.gridTemplateColumns` set to the stored template string (e.g.
`"1fr 1fr"`). Acts as a shadow root.

### Registration

Layouts ship behind the `layouts` feature flag. To add the capability to a
custom composition, contribute a descriptor via `extraFeatures`:

```tsx
<Editor
  extraFeatures={[
    {
      id: "layouts",
      plugin: LayoutPlugin,
      nodes: [LayoutContainerNode, LayoutItemNode],
      slashCommandIds: ["columns"],
    },
  ]}
/>
```

### Inserting a layout programmatically

```tsx
import { INSERT_LAYOUT_COMMAND } from "../plugins/layout/commands";

editor.dispatchCommand(INSERT_LAYOUT_COMMAND, {
  templateColumns: "1fr 1fr 1fr", // three equal columns
});

// replace a specific node:
editor.dispatchCommand(INSERT_LAYOUT_COMMAND, {
  templateColumns: "1fr 3fr",
  targetNodeKey: someNodeKey,
});
```

<Callout title="Any valid CSS grid template works" variant="tip">
  The `templateColumns` value is written directly to
  `style.gridTemplateColumns`. You can pass any valid CSS grid template string
  — the column count is derived by splitting on whitespace, so named tracks or
  `repeat()` expressions should be pre-resolved to explicit values before
  passing them in.
</Callout>
