### Registration

Multi-column layouts ship as the optional `@pytah/editor-layouts` registry item. Install it and compose `layoutFeature` via `extraFeatures`:

```tsx
import { layoutFeature } from "@/components/editor/plugins/layout/feature";

<Editor extraFeatures={[layoutFeature]} />;
```

### Inserting a layout programmatically

```tsx
import { INSERT_LAYOUT_COMMAND } from "@/components/editor/plugins/layout/commands";

editor.dispatchCommand(INSERT_LAYOUT_COMMAND, {
  templateColumns: "repeat(3, 1fr)", // three equal columns
});

// replace a specific node:
editor.dispatchCommand(INSERT_LAYOUT_COMMAND, {
  templateColumns: "1fr 3fr",
  targetNodeKey: someNodeKey,
});
```

<Callout title="Any valid CSS grid template works" variant="tip">
  The `templateColumns` value is written directly to
  `style.gridTemplateColumns`. `getLayoutColumnCount` parses both explicit track
  lists (`1fr 2fr 1fr`) and nested CSS functions such as `repeat(3, 1fr)` or
  `repeat(2, minmax(0, 1fr)) 200px`, and structural transforms keep the
  container and column children valid after arbitrary edits.
</Callout>
