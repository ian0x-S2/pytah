## plugin.tsx

`DraggableBlockPlugin` wraps Lexical's experimental
`DraggableBlockPlugin_EXPERIMENTAL`. It listens for the root element via
`registerRootListener` to obtain the `anchorElem` (the root's parent container)
and only renders when the editor is editable. The grip handle is a
`GripVerticalIcon` that appears on hover, and a thin primary-coloured line
shows the drop target position.

## Registration

Draggable blocks ship behind the `draggableBlocks` feature flag (editor-only).
To add it to a custom composition, contribute a descriptor via
`extraFeatures`:

```tsx
<Editor
  extraFeatures={[
    {
      id: "draggableBlocks",
      plugin: DraggableBlockPlugin,
    },
  ]}
/>
```

<Callout title="Editor-only" variant="tip">
  `DraggableBlockPlugin` checks `useLexicalEditable()` and renders `null` in
  read-only mode, so it is safe to mount unconditionally.
</Callout>

<Callout title="Anchor element">
  The plugin needs the root element's *parent* as the anchor so the floating
  grip can be positioned outside the scrollable content area.
  `registerRootListener` fires once on mount (and again if the root changes),
  so `anchorElem` is always up to date.
</Callout>
