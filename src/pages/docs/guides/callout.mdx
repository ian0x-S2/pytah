## Markdown Format

Callout blocks convert to and from standard GitHub Flavored Markdown alerts:

```markdown
> [!NOTE] Information to take into account.

> [!TIP] Helpful advice or recommendation.

> [!WARNING] Critical warning that demands attention.

> [!CAUTION] Negative consequences of an action.
```
