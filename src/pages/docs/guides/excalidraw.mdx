## node.tsx

`ExcalidrawNode` extends `DecoratorNode` and stores the whole drawing as a
serialized JSON string in `__data`, plus optional `__width`/`__height`
dimensions for resizing. HTML export embeds the currently rendered svg so
pasted content stays visible outside the editor, and tags the element with a
`data-lexical-excalidraw-json` attribute that `importDOM` uses to restore an
editable drawing on paste.

## scene.ts

The stored payload keeps only what is needed to re-open a drawing: elements,
the files referenced by image elements, and a small subset of app state. The
helpers below normalize parsing so corrupt or foreign data degrades to an
empty scene instead of throwing.

## Lazy loading

The `@excalidraw/excalidraw` runtime is large, so nothing imports it at module
scope. Both consumers load it on demand:

- `image.tsx` dynamically imports `exportToSvg` when a scene preview renders.
- `modal.tsx` lazily loads the `<Excalidraw>` editor plus its stylesheet the
  first time the drawing surface opens.

Documents that never contain a drawing never download the package.

## component.tsx

The decorator component owns the interaction model: click selects the block,
double-click (or the pencil affordance) opens the editing surface, drag start
is suppressed, and Backspace/Delete removes a selected empty-handed block.
Saving writes the serialized scene back into the node; discarding removes the
node entirely when it was inserted empty.

## plugin.tsx

`ExcalidrawPlugin` registers `INSERT_EXCALIDRAW_COMMAND` and inserts an empty
drawing block via `$insertNodeToNearestRoot`. Because an empty, editable block
opens its editing surface on mount, slash commands (`/drawing`) and toolbar
inserts reuse this single path — no dialog plumbing in either surface.

## Registration

Excalidraw drawings ship behind the `excalidraw` feature flag. To add the
capability to a custom composition, contribute a descriptor via
`extraFeatures`:

```tsx
import { $createExcalidrawNode, $isExcalidrawNode, ExcalidrawNode } from "@/components/editor/core/nodes/excalidraw/node";
import { ExcalidrawPlugin } from "@/components/editor/plugins/excalidraw/plugin";

<Editor
  extraFeatures={[
    {
      id: "excalidraw",
      plugin: ExcalidrawPlugin,
      nodes: [ExcalidrawNode],
      slashCommandIds: ["excalidraw"],
    },
  ]}
/>
```

### Inserting a drawing programmatically

```tsx
editor.dispatchCommand(INSERT_EXCALIDRAW_COMMAND, undefined);
```

<Callout title="Fonts and assets" variant="tip">
  Excalidraw loads its hand-drawn fonts from a public CDN by default. Set
  `window.EXCALIDRAW_ASSET_PATH` before the editor mounts to self-host the
  assets from your own origin.
</Callout>
