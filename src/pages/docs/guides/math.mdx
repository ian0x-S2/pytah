## Scoped KaTeX Stylesheet

`MathComponent` imports `katex` and `katex/dist/katex.min.css` directly inside the optional `@pytah/editor-math` feature so equations render synchronously on frame 0 without requiring a global CSS import in projects that do not install math.

## Markdown Syntax

- **Inline equations**: `$e = mc^2$` (currency expressions like `$5 and $10` are ignored so prose prices do not accidentally convert into math).
- **Block equations**: both single-line `$$x^2 + y^2 = z^2$$` and multiline fenced blocks:

```markdown
$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$
```

## Registration

Math support ships as the optional `@pytah/editor-math` registry item. Install it and pass `mathFeature` via `extraFeatures`:

```tsx
import { mathFeature } from "@/components/editor/plugins/math/feature";

<Editor extraFeatures={[mathFeature]} />;
```
