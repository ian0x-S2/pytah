<Callout title="Feature guide">
  The Table of Contents (`@pytah/editor-toc`) renders a compact right-margin
  outline rail that expands into a full heading popover on hover or keyboard
  focus, highlighting the active section as you scroll.
</Callout>

## Usage

Install `@pytah/editor-toc` and mount `EditorWithToc` (or render `<EditorTableOfContents />` inside your own `slots.shell`):

```tsx
import { EditorWithToc } from "@/components/editor/plugins/toc/editor-with-toc";

export function DocumentPage() {
  return <EditorWithToc minimal toolbar="full" />;
}
```

Pass `toc={null}` to hide the rail conditionally (for example, in zen mode), or pass a custom React node to replace the default sidebar.
