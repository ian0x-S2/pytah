## resizer.tsx

Renders four corner drag handles (`ne`, `se`, `sw`, `nw`) as
absolute-positioned divs. The overlay mirrors the resized element's true box
via offset-based bounds syncing, so handles stay glued to it even when an
ancestor container clamps the element's layout width. Uses pointer events to
track drag distance and update the image's inline style in real-time, then
calls `onResizeEnd` with the final pixel dimensions. Other block types (like
drawings) reuse `ImageResizer` with `edgeHandles` for free axis resizing and
a `decorations` slot for chrome that must hug the handles.

<CodeBlock label="src/components/editor/plugins/image/resizer.tsx" language="tsx">
  {imageResizerSource}
</CodeBlock>

## resize-geometry.ts

The pure resize math shared by every consumer of `ImageResizer`: direction
types, min-size clamps, cursor mapping, and `computeNextSize` (corner drags
lock the aspect ratio; edge drags move one axis independently). Keeping it
component-free lets tests cover it headlessly.

## Registration

The image capability ships in the default editor behind the `images` feature
flag. To add it (or any whole capability) to a custom composition, contribute
a descriptor via `extraFeatures` — no edits to `core/config.ts` or
`ui/content.tsx`:

```tsx
<Editor
  extraFeatures={[
    {
      id: "images",
      plugin: ImagePlugin,
      nodes: [ImageNode],
      transformers: [IMAGE_MARKDOWN_TRANSFORMER],
      slashCommandIds: ["image"],
    },
  ]}
/>
```

Built-in capabilities are registered the same way in `core/features.tsx`, so
a flag toggles the node, plugin, transformers, and slash command together.

### Inserting an image programmatically

```tsx
editor.dispatchCommand(INSERT_IMAGE_COMMAND, {
  src: "https://example.com/photo.jpg",
  altText: "A photo",
  alignment: "center",
});
```

<Callout title="File paste / drop is automatic" variant="tip">
  `ImagePlugin` intercepts `PASTE_COMMAND` and `DROP_COMMAND` automatically.
  Any image file dragged into the editor or pasted from the clipboard is
  converted to a data URL and inserted as an `ImageNode`.
</Callout>
