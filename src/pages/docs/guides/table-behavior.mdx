<Callout title="Depends on @lexical/table">
  `TableBehaviorPlugin` composes the official `<TablePlugin>` from
  `@lexical/react/LexicalTablePlugin`. No custom table nodes are needed — the
  plugin adds the floating action-menu UI on top.
</Callout>

## plugin.tsx

Three components in one file. `TableBehaviorPlugin` is the public entry point —
it renders `<TablePlugin>` and conditionally mounts the action-menu container.
`TableCellActionMenuContainer` listens for selection changes and positions a
small chevron button at the active cell. `TableActionMenu` is the popover
content with insert/delete actions.

### Registration

Table behavior ships behind the `tables` feature flag. To add it to a custom
composition, contribute a descriptor via `extraFeatures`:

```tsx
<Editor
  extraFeatures={[
    {
      id: "tables",
      plugin: TableBehaviorPlugin,
      transformers: [TABLE_MARKDOWN_TRANSFORMER],
      slashCommandIds: ["table"],
    },
  ]}
/>
```

<Callout title="Anchor element" variant="tip">
  The action-menu portal renders inside `anchorElem`, which is the *parent* of
  the editor root (obtained via `rootElement.parentElement`). This ensures the
  absolute position calculations are relative to the same offset parent as the
  table cells.
</Callout>
