## plugin.tsx

The plugin subscribes to `SELECTION_CHANGE_COMMAND` and the update listener, then renders the toolbar as a fixed portal over the selection. The single row is ordered: the "Turn into" block dropdown (reusing `BlockTypeDrop` in its `compact` variant — conversion options only, single-line items, menu as wide as its trigger, feature-gated through the resolved command ids), inline format toggles, color pickers, link, and the "⋮" overflow menu. An open-surface ref prevents the toolbar from disappearing while a color popover or the overflow menu is open.

### How to mount it

The floating toolbar ships behind the `floatingToolbar` feature flag. To add it to a custom composition, contribute a descriptor via `extraFeatures`:

```tsx
<Editor
  extraFeatures={[
    {
      id: "floatingToolbar",
      plugin: FloatingToolbarPlugin,
    },
  ]}
/>
```

<Callout title="Floating surface stability" variant="tip">
  The plugin uses a ref counter (not state) to track whether a color picker or
  the overflow menu is open. This avoids re-registering the
  `SELECTION_CHANGE_COMMAND` listener on every open/close cycle while still
  preventing the toolbar from being hidden while the user browses swatches or
  menu options.
</Callout>
