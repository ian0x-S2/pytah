## plugin.tsx

The plugin subscribes to `SELECTION_CHANGE_COMMAND` and the update listener,
then renders the toolbar as a fixed portal over the selection. A
`isColorPickerOpenRef` prevents the toolbar from disappearing while a color
popover is open.

### How to mount it

The floating toolbar ships behind the `floatingToolbar` feature flag. To add
it to a custom composition, contribute a descriptor via `extraFeatures`:

```tsx
<Editor
  extraFeatures={[
    {
      id: "floatingToolbar",
      plugin: FloatingToolbarPlugin,
    },
  ]}
/>
```

<Callout title="Color picker stability" variant="tip">
  The plugin uses a `ref` (not state) to track whether a color picker is open.
  This avoids re-registering the `SELECTION_CHANGE_COMMAND` listener on every
  open/close cycle while still preventing the toolbar from being hidden while
  the user browses swatches.
</Callout>
