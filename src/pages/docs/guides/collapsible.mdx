<Callout title="Chrome vs. other browsers">
  Native `<details>`/`<summary>` elements handle expand/collapse in non-Chrome
  browsers automatically. Chrome requires manual DOM manipulation because it
  does not support the `hidden="until-found"` attribute. Both paths are
  handled in the node's `createDOM` / `updateDOM` methods.
</Callout>

## container-node.ts

The root of the collapsible structure. Stores a single boolean `__open` and
exposes `toggleOpen()`. Acts as a shadow root so inner selections stay
contained.

## title-node.ts

Renders as a `<summary>` element. On Chrome, a click listener calls
`container.toggleOpen()` via `editor.update()`. Pressing Enter in the title
jumps into the content body.

### Registration

The collapsible capability ships behind the `collapsible` feature flag. To add
it to a custom composition, contribute a descriptor via `extraFeatures`:

```tsx
<Editor
  extraFeatures={[
    {
      id: "collapsible",
      plugin: CollapsiblePlugin,
      nodes: [
        CollapsibleContainerNode,
        CollapsibleTitleNode,
        CollapsibleContentNode,
      ],
      slashCommandIds: ["collapsible"],
    },
  ]}
/>
```

### Inserting programmatically

```tsx
editor.dispatchCommand(INSERT_COLLAPSIBLE_COMMAND, undefined);
// or replace a specific node:
editor.dispatchCommand(INSERT_COLLAPSIBLE_COMMAND, { targetNodeKey: "abc" });
```
