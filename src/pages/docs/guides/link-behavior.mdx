## constants.ts

Two `AutoLinkPlugin` matchers — one for URLs and one for email addresses. Plain
`www.` URLs are normalised to `https://` automatically; email addresses get the
`mailto:` scheme.

## utils.ts

Three URL helpers used by the floating editor and `LinkPlugin`'s
`validateUrl` prop.

| Export | Purpose |
| --- | --- |
| `LINK_PLACEHOLDER_URL` | Sentinel value (`"https://"`) used as the default when creating a new link so the input is pre-filled. |
| `normalizeEditorLinkUrl(value)` | Trims whitespace, adds `mailto:` for bare email addresses, adds `https://` for `www.` prefixed strings. |
| `isValidEditorLinkUrl(value)` | Returns `true` for any URL whose protocol is one of `http:`, `https:`, `mailto:`, `sms:`, `tel:` — or the placeholder. |
| `sanitizeEditorLinkUrl(value)` | Returns `about:blank` for disallowed protocols, otherwise returns the normalised URL. |

## floating-link-editor.tsx

`FloatingLinkEditorPlugin` is a portal-based floating panel that appears below
the selection whenever a link node is selected. It has two modes: a **preview
mode** (URL + edit / delete / open-in-tab buttons) and an **edit mode** (URL
input + confirm / cancel buttons).

### Commands handled

| Command | Priority | Behaviour |
| --- | --- | --- |
| `SELECTION_CHANGE_COMMAND` | LOW | Syncs link URL and panel position on every selection change. |
| `OPEN_FLOATING_LINK_EDITOR_COMMAND` | HIGH | Enters edit mode immediately (dispatched by the floating toolbar's link button). |
| `KEY_DOWN_COMMAND` | HIGH | Cmd/Ctrl+K toggles the link: removes it if the selection is already a link, otherwise creates a new one and enters edit mode. |
| `KEY_ESCAPE_COMMAND` | HIGH | Dismisses the panel when a link is focused. |
| `CLICK_COMMAND` | LOW | Cmd/Ctrl+click opens the link URL in a new tab while editing. |

## Registration

No custom nodes are required. `LinkBehaviorPlugin` is part of the
always-mounted default stack, and the floating link editor ships behind the
`floatingLinkEditor` feature flag. To add the floating editor to a custom
composition, contribute a descriptor via `extraFeatures`:

```tsx
<Editor
  extraFeatures={[
    {
      id: "floatingLinkEditor",
      plugin: FloatingLinkEditorPlugin,
    },
  ]}
/>
```

<Callout title="Keyboard shortcut" variant="tip">
  Cmd/Ctrl+K is handled entirely inside `FloatingLinkEditorPlugin`. Pressing it
  on plain text creates a link and opens the editor; pressing it again on an
  existing link removes it. No toolbar wiring is needed for the shortcut to
  work.
</Callout>
