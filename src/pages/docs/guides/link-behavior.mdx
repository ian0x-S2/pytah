## utils.ts

URL helpers used by the floating editor and `LinkPlugin`'s `validateUrl` prop.

| Export | Purpose |
| --- | --- |
| `LINK_PLACEHOLDER_URL` | Sentinel value (`"https://"`) used as default when creating a new link so the input is pre-filled. |
| `normalizeEditorLinkUrl(value)` | Trims whitespace, adds `mailto:` for bare email addresses, adds `https://` for `www.` prefixed strings. |
| `isValidEditorLinkUrl(value)` | Returns `true` for any URL whose protocol is one of `http:`, `https:`, `mailto:`, `sms:`, `tel:` — or the placeholder. |
| `sanitizeEditorLinkUrl(value)` | Returns `about:blank` for disallowed protocols, otherwise returns the normalised URL. |

## Smart Link Paste (paste.ts)

When pasting URLs, the editor evaluates current selection state:

1. **Selection with text highlighted**: Pasting a URL wraps the highlighted text into a link (`LinkNode`) instead of overwriting it with the raw URL string. Naked `www.` addresses are automatically prepended with `https://`.
2. **Collapsed caret**: Pasting a URL inserts the link text and immediately opens the **Link Paste Format Menu** beneath the newly created link.

## Link Paste Format Menu (floating-link-paste-menu.tsx)

When a link is pasted with a collapsed caret, a floating menu rendered with Base UI `<Popover>` appears directly under the pasted link.

### Available Formats

| Option | Identifier | Description |
| --- | --- | --- |
| **Paste inline link** | `inline-link` | Leaves standard inline anchor text link. |
| **Inline – Weblink** | `inline-weblink` | Converts to an inline badge with favicon and page title. |
| **Small card – Weblink** | `small-weblink` | Converts the block to a compact side-by-side card with thumbnail. |
| **Wide card – Weblink** | `wide-weblink` | Converts the block to a full-width hero banner card. |
| **Remove link** | `remove-link` | Replaces link with plain unlinked text. |

### Keyboard Navigation & Accessibility

The paste menu uses Base UI's `<Popover>` and `<PopoverContent>` with full accessible keyboard navigation:

- <kbd>↓</kbd> / <kbd>↑</kbd>: Navigates through options with cyclical wrapping
  (roving tabindex `tabIndex={0}` on active, `-1` on others). Works seamlessly
  both from the editor caret and when the popover is focused.
- <kbd>Home</kbd> / <kbd>End</kbd>: Jumps directly to the first or last option.
- <kbd>Tab</kbd> / <kbd>Shift+Tab</kbd>: Cycles between options within the menu.
- <kbd>Enter</kbd> / <kbd>Space</kbd>: Executes the selected format
  transformation and refocuses the editor.
- <kbd>Escape</kbd>: Dismisses the menu and leaves the inline link intact.
- **Continuous typing**: Pressing any printable character or Backspace immediately dismisses the menu and lets typing flow naturally into the editor without swallowed keystrokes.

## floating-link-editor.tsx

The link surfaces follow the Google-Docs interaction model:

1. **Hover chip (`preview`)** — hovering a link shows a compact preview (`FloatingLinkPreviewChip`) anchored 6px below the link. Renders through shadcn `HoverCard` (Base UI preview card) with automatic dismissal and travel bridging.
2. **Edit card (`edit`)** — clicking **Edit** on the chip, pressing Cmd/Ctrl+K, or clicking the floating toolbar's link button opens the full card (`Popover`) with link-text and URL inputs.

### Commands handled

| Command | Priority | Behaviour |
| --- | --- | --- |
| `SELECTION_CHANGE_COMMAND` | LOW | Syncs link state and surface anchoring on every selection change. |
| `OPEN_FLOATING_LINK_EDITOR_COMMAND` | HIGH | Opens the edit card. |
| `KEY_DOWN_COMMAND` | HIGH | Cmd/Ctrl+K toggles the link. |
| `KEY_ESCAPE_COMMAND` | HIGH | Closes the card/chip when the selection lives in a link. |
| `CLICK_COMMAND` | LOW | Cmd/Ctrl+click opens the link URL in a new tab while editing. |

## Registration & Flags

Both the floating link editor and link paste menu are enabled by default and can be toggled via `EditorFeatureFlags`:

```tsx
<Editor
  features={{
    floatingLinkEditor: true, // Google Docs-style hover chip & edit card
    linkPasteMenu: true, // Floating paste format menu on URL paste
  }}
/>
```
