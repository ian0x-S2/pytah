## Examples

### Minimal Product Editor

```tsx
<Editor editable minimal toolbar="basic" />
```

### Initial Code Block Theme

```tsx
<Editor codeBlockTheme="tokyo-night" />
```

### Replace Outputs

```tsx
<Editor
  chrome={{ outputs: true }}
  slots={{
    outputs: ({ snapshot }) => (
      <section>
        <h2>Markdown</h2>
        <pre>{snapshot.markdown}</pre>
      </section>
    ),
  }}
/>
```

### Register Extra Node

```tsx
<Editor extraNodes={[CalloutNode]} />
```

### Contribute a Whole Feature

```tsx
import { calloutFeature } from "@/components/editor/plugins/callout/feature";

<Editor extraFeatures={[calloutFeature]} />;
```

Or define a custom `ExtraEditorFeature` descriptor with its own `slashCommands`:

```tsx
<Editor
  extraFeatures={[
    {
      id: "callout",
      plugin: CalloutPlugin,
      nodes: [CalloutNode],
      transformers: [CALLOUT_MARKDOWN_TRANSFORMER],
      slashCommands: [
        {
          command: {
            description: "Highlighted note box",
            icon: InfoIcon,
            id: "callout",
            keywords: ["note", "callout"],
            label: "Callout",
          },
          run: (editor) => {
            editor.dispatchCommand(INSERT_CALLOUT_COMMAND, { type: "note" });
          },
        },
      ],
    },
  ]}
/>
```

Each descriptor bundles the plugin, nodes, markdown transformers, and slash-command contributions (`{ command, run }` pairs) for one capability, wired together per-editor by the composition surface.

### Error Handling & Weblink Favicon Control

```tsx
<Editor
  onError={(error) => reportEditorError(error)}
  weblinkFaviconResolver={false} // opt out of external favicon requests (or pass `(host) => string`)
/>
```
